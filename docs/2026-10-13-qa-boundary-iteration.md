## 发现及修复

| 问题 | 根因 | 修改后的行为 |
| --- | --- | --- |
| 设备环境内部 Top3 混入其他大类 | 排名范围与总分母范围混在一起 | 排名保留父类范围，分母单独标记为当前范围、全部或所选项 |
| Top1 等请求仍给 Top3 | 受控路径固定取三项 | 支持 Top1 至 Top50，不能覆盖的条件退出受控模板 |
| 明确要求三个缺陷自身占比仍使用全量分母 | “内部”识别过宽或自身分母意图丢失 | 区分父类内部与 TopN 自身；从原始数量计算分母 |
| 指定三类占全部的比例，却改成三类自身占比 | 查询筛选同时缩小了分母 | 分子只展示指定类，全部分母保留其他大类 |
| 改日期并改图时复用旧月份数据 | 展示修改快捷路径吞掉新日期/筛选 | 有明确数据范围变化则重新查询，不按纯展示修改执行 |
| 数量 Top3 柱图改饼图把 Top3 当成全部 | 数量模式缺少全量差额处理 | 有已验证全量分母时添加“其他缺陷”，保持原分母；明确选择自身占比时才改分母 |
| 从设备环境占比改为全部缺陷占比后仍用旧分母 | AI 问题增强把明确的全部分母改写成“同一范围” | 把明确分母范围作为结构化请求字段传入图执行状态，避免被改写丢失 |
| 三图生成顺序或自然语言目标选错 | 固定展示顺序；含糊引用默认最近一张 | 按第1/2/3张要求生成；多图含糊修改要求指定编号或名称 |
| 一张实际图却被识别为两张 | 多个 SQL 步骤的展示配置被计为独立图表 | 同一报告有实际 CHART 时，以实际图表为准，不把中间查询配置算成额外图表 |
| 分两轮设置坐标轴得到下限大于上限 | 仅校验本轮输入，没有与已存边界合并校验 | 使用修改后的实际上下限校验，非法修改保留原图 |
| 报告文字精简走错路径或改变数字 | 规划输出空图形类型与无关数据字段；报告整体交给模型改写 | 明确风格修改直接路由；保护含数字段落、表格和代码，恢复原始事实块，违规改写不发布 |
| 规划时点击停止无效 | 规划阶段没有图执行线程可停止 | 从提交开始登记执行；按会话取消规划，晚到的规划结果不再启动图执行 |
| 按线程停止后连接仍等待 | 停止清理缺少终止事件，心跳流继续等待 | 停止发出终止事件并清理；验证停止后同会话可再次提问 |
| 完整明确的缺陷问题仍被澄清 | 模型可行性判断误拦截 | 仅对已有受控模板、日期工厂范围明确且表结构可用的请求直接通过 |
| 完整分类统计偶尔只返回总计 | 模型精细选表漏掉缺陷字典，使受控统计路径失效 | 对受控模板命中的请求保留已召回的明细、字典表，不凭空创建表结构 |
| Top3首次回答正确，改饼图却缺少可靠分母 | 模型追加Python计算，其重试改写了原SQL，完整快照被普通结果覆盖 | 模板覆盖的请求使用一次SQL快照直接生成报告和图表，避免后续重算覆盖来源 |
| 明确的未来日期记录数问题被反复追问 | 会话规划把无数据问题误认为口径不清 | 明确单厂单日缺陷明细记录数进入查询；0条记录不代表实际没有不良 |
| 具体缺陷在父类范围内未出现时可能返回父类合计 | 报告匹配具体缺陷失败后回退到大类表格 | 报告说明指定范围未查到该具体缺陷，不拿父类合计替代，不推断实际数量为零 |

核心文件是 `ConversationService`、`ArtifactReferenceResolver`、`PresentationSpecEditor`、`PaintDefectAnalysis`、`TableRelationNode`、`FeasibilityAssessmentNode`、`PlannerNode`、`ReportFactsProtector` 及会话/图执行控制器。新增的取消登记仅管理当前进程内执行。

## 人工复测方式

每组新开一个会话，组内按顺序提问。相互独立的统计题各用新会话；改图、改分母、改日期必须接着原问题问。

1. 查询一厂2026年6月塑件缺陷、喷房缺陷、设备环境完整明细数量，用柱状图展示。
   接着问：上面这张改成饼图，展示三类自身的占比。
   应保留1375/542/4456，分母6373，没有重新生成 SQL。
2. 查询一厂2026年6月喷涂真实具体缺陷Top3数量，用柱状图展示，按完整明细统计。
   接着问：改成饼图。再问：改回柱状图。
   饼图应含3397/671/623及其他1931；改回仍是原数量。
3. 查询一厂2026年6月喷涂设备环境大类内部的真实具体缺陷Top3各占设备环境合计多少，用柱状图展示。
   接着问：改成占全部缺陷数量的比例，其他要求不变。
   应从分母4456改为6622，排名仍为杂质/水滴/凹陷；不足以本地计算全量分母时重新查询。
4. 查询一厂2026年6月喷涂完整缺陷明细，统计塑件缺陷、喷房缺陷、设备环境，生成三张图：第1张为三类数量柱状图；第2张为三类自身占比饼图；第3张为全部具体缺陷Top3数量柱状图。
   接着问：改成占全部缺陷的比例。
   应询问修改哪张图。指定第1张后才修改，另两张保持原样。
5. 对一张数量图依次说：Y轴下限设为6000。Y轴上限设为5000。
   第二句应被拒绝，原图不得变成非法坐标范围。
6. 对已生成的报告说：把上一份报告的文字改为精简版，保留所有数据、表格和图表，不要重新查询。
   原数字、表格、图表保持；模型若破坏事实块则保留原报告并明确说明。
7. 问：一厂2099年1月1日喷涂完整缺陷明细有几条记录？是否可以据此认定当天没有不良？
   当前库应为0条，汇总NULL；不能据此认定实际没有不良，也不能绘制0缺陷构成图。
8. 问：查询一厂2026年6月喷涂设备环境大类中的前划完整明细数量是多少？
   应说明该父类筛选下没有匹配明细，不把设备环境4456或塑件前划671当成此问题的答案。
